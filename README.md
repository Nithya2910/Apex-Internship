## ⚙️ Installation & Setup

### 1. Install Local Server

Download and install any one:

* XAMPP
* WAMP
* MAMP

Start:

* Apache Server
* MySQL Server

Verify installation by opening:

```text
http://localhost
```

---

### 2. Install Code Editor

Recommended:

* Visual Studio Code
* Sublime Text

Useful VS Code Extensions:

* PHP Intelephense
* PHP Server
* GitLens
* Prettier

---

### 3. Configure Git

Check Git installation:

```bash
git --version
```

Configure Git:

```bash
git config --global user.name "Your Name"
git config --global user.email "your@email.com"
```

---

### 4. Initialize Repository

```bash
git init
```

Add project files:

```bash
git add .
```

Create first commit:

```bash
git commit -m "Initial commit - Task 1 Setup"
```

---

## ▶️ Running the Project

Place the project folder inside:

```text
xampp/htdocs/
```

Access through browser:

```text
http://localhost/Task-1-Development-Environment/
```
